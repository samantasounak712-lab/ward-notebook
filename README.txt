Ward Notebook: installable, offline-capable version

1. Host these files together over HTTPS (required for install and offline mode). Easy free options:
   - Netlify: drag this unzipped folder onto app.netlify.com/drop
   - GitHub Pages: upload the files to a repo and enable Pages
2. Open the hosted address on your tablet.
3. Chrome: menu > Install app. Safari: Share > Add to Home Screen.
After the first load it opens offline. Voice typing still needs internet.
Data stays in that browser on that device. Export regularly.
Use initials or hospital IDs, not names, unless your hospital approves otherwise.
